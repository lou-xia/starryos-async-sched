# 本科毕设项目

## 简述

在 Starry-OS 的体系结构基础上，探索一种无需依赖专用硬件支持的统一任务调度与中断管理的软件化方案，设计一个相对独立的异步调度模块。


## 背景

1. 目前的 Starry-OS 中异步机制较为基础，同时具有模块化的特性，可以作为模板操作系统
2. 赵方亮的 taic 需要定制化硬件，维护和更新成本高；使用软件虽然性能不如硬件，但具有可移植性和可扩展性
3. 赵方亮提出的以执行流为调度单位的思想具有创新性，可以尝试在软件上实现

## 平台

模板操作系统：Starry-OS
指令集：risc-v

## 主要内容

1. 学习 Starry-OS 代码实现、参考赵方亮 taic 和罗熙 vdso 相关工作
2. 将赵方亮的基于执行流的异步调度机制以软件的形式移植到 Starry-OS 上。重点在于将原本 unikernel 中的函数调用形式转换为任务切换形式
3. 与胡嘉晨交流，对异步调度机制进行优化，期望实现一个兼容多平台的，在无定制硬件条件下有明显性能提升的独立模块
4. 尝试对调度算法进行优化，解决 FIFO 的局限性
5. 进行性能测试和上板测试
